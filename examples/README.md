# SLUG 1.0 examples

Everything in this directory uses the final v1 language surface. Historical pre-v1 examples were moved to `historical/examples-pre-v1/` so removed hexadecimal syntax and obsolete comment forms are not presented as current SLUG.

Run any example with:

```sh
slug check examples/hello.slg
slug run examples/hello.slg
```

The examples intentionally stay small; the conformance suite in `tests/` is the executable language authority.
