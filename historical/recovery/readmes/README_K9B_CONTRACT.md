# SLUG K9B — v1 Contract Freeze

K9B is the public language/interface freeze layered on the clean, optimized K9A bootstrap base.

Start here:

- `docs/SLUG_V1_SPECIFICATION.md` — canonical SLUG 1.0 semantics;
- `docs/SLUG_PUBLIC_CLI_V1.md` — stable public compiler CLI target;
- `docs/SLUG_V1_STANDARD_MODULES.md` — standard module identities and v1.0 exports;
- `PUBLIC_CONTRACT.json` — machine-readable contract constants;
- `docs/SLUG_V1_STABILITY_AND_AUTHORITY.md` — authority order;
- `docs/K9B_CLI_IMPLEMENTATION_GAP.md` — what the current native CLI still must implement.

K9B does not alter the canonical compiler/runtime. The K9A seed hash and self-host compiler state are carried unchanged.
